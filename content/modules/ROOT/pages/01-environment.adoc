= Environment

== Clusters

|===
| Role | Domain | Nodes | Purpose

| Source
| `source.cclm.local`
| SNO control plane + 2 workers
| Runs seed VMs; MTV *source* provider

| Destination
| `dest.cclm.local`
| SNO (control plane only)
| MTV *destination* provider; receives migrations
|===

API / Ingress VIPs share the machine network (`10.0.0.0/24`):

* Source: `10.0.0.10`
* Destination: `10.0.0.110`

== Storage

Both clusters attach to the *same* external Ceph RBD pool (Troshka-provisioned
project Ceph exported into each nested ODF). MTV StorageMaps target
`ocs-external-storagecluster-ceph-rbd` so disks move with live migration
without copying data over the migration network.

== Operators (post-install)

Installed on both clusters by the `demo_workloads` CCLM chain:

* OpenShift Virtualization (CNV) with `decentralizedLiveMigration: true`
* Migration Toolkit for Virtualization (MTV / Forklift)
* ODF external mode (shared Ceph)
* Submariner (broker on source)
* nmstate, cert-manager, MetalLB
