= OpenShift Virtualization Basics

== Introduction

This module introduces you to the fundamentals of creating and managing virtual machines in OpenShift Virtualization. You will learn how to navigate the Virtualization perspective, create VMs from templates, configure resources, and manage VM lifecycle states. These essential skills form the foundation for all subsequent advanced topics.

.*Goals*

* Create a new OpenShift project for managing virtual machines
* Explore the OpenShift Virtualization user interface and features
* Create a Linux virtual machine from a template
* Review and configure virtual machine resources (storage, networking, hardware)
* Control virtual machine power states and lifecycle

+
image::exercise0/12_Create_VM_Button.png[title="Create VM Button", link=self, window=blank, width=100%]

image::exercise0/13_Create_VM_Templates.png[title="List of Templates", link=self, window=blank, width=100%]

* *Network* — VM IP address and hostname
* *Utilization* — CPU, memory, storage, and network throughput metrics

[[admin_vms]]
== Administer Virtual Machines

=== Configuration Overview

. Click the *Configuration* tab to access VM settings and resource modifications.
+
image::exercise0/20_Configuration_Tab.png[title="Configuration Tab", link=self, window=blank, width=100%]

The Configuration tab includes seven subtabs:

* *Details* — Modify CPU, memory, hostname, boot order, and passthrough devices
* *Storage* — Add or remove disks; attach ConfigMaps, Secrets, Service Accounts
* *Network* — View and add network interfaces
* *Scheduling* — Configure node affinity, tolerations, and eviction strategies
* *SSH* — Configure SSH access via load balancer or key injection
* *Initial run* — Configure cloud-init (Linux) or sys-prep (Windows) settings
* *Metadata* — Manage labels and annotations for automation and tagging

=== Review Storage Configuration

. Click the *Storage* subtab.
+
image::exercise0/21_Storage_Tab.png[title="Storage Tab", link=self, window=blank, width=100%]

The default StorageClass (*ocs-external-storagecluster-ceph-rbd*) is provided by OpenShift Data Foundation (ODF). Each storage provider defines different storage classes with specific performance and availability characteristics.

=== Review Network Configuration

. Click the *Network* subtab.
+
image::exercise0/22_Network_Tab.png[title="Network Tab", link=self, window=blank, width=100%]

Quick-created VMs have a default masquerade interface on the Pod Network, which:
* Connects the VM to the software-defined network (SDN)
* Provides cluster-to-cluster egress
* Enables access from other VMs and pods within the cluster
* Supports external access via Route, Service (type: LoadBalancer), or Network Attachment Definitions

[[vm_state]]
== Control Virtual Machine State

As a user with virtualization permissions, you can manage VM lifecycle states through the web console.

=== State Management Options

. Click the *Overview* tab to return to the summary screen.

. In the top right corner, you'll see state control buttons and an *Actions* menu.
+
image::exercise0/23_VM_State_Actions.png[title="VM State Buttons", link=self, window=blank, width=100%]

State management options:

* *Stop* — Gracefully shut down the VM
* *Restart* — Reboot the VM (requires guest integrations)
* *Pause* — Freeze the process without CPU/IO access (memory remains allocated at hypervisor level)
* *Start* — Boot a stopped VM

=== Practice State Transitions

. Click the *Stop* button and wait until the VM enters *Stopped* state.
+
image::exercise0/25_VM_Stopped.png[title="The VM is Stopped", link=self, window=blank, width=100%]

. Click *Actions* > *Control* to see the context menu. Notice that *Start* is now available while *Restart* and *Pause* are greyed out.
+
image::exercise0/26_VM_Actions_List_Stopped.png[title="Action Menu with VM Stopped", link=self, window=blank, width=100%]

. Click *Start* and wait for the *Running* status.

. Use *Actions* > *Control* > *Pause* to pause the VM. This is useful for immediately freeing node resources without losing application state.
+
image::exercise0/27_VM_Actions_Paused.png[title="The VM is Paused", link=self, window=blank, width=100%]

. Resume the VM by clicking *Unpause* from the *Actions* > *Control* menu or using the shortcut button.
